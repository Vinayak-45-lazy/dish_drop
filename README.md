# 🍽️ DishDrop — Food Delivered Fast

A modern full-stack food delivery platform inspired by Swiggy/Zomato, built with MERN + AI integration.

---

## 🚀 Features
- 🍔 Browse restaurants & order food  
- 🤖 AI-powered food recommendations & chatbot  
- 🔍 Smart search (e.g., "spicy biryani under 200")  
- 📍 Real-time order tracking (maps)  
- 💳 Razorpay test payment integration  
- 👨‍🍳 Restaurant & Delivery dashboards  
- 🛠️ Admin panel with analytics  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** Firebase Firestore  
- **Auth:** Firebase Authentication  
- **AI:** Groq (LLM integration)  
- **Others:** Cloudinary, Razorpay, Leaflet Maps  

---

## 👥 User Roles
- Customer (order food, track orders)  
- Restaurant Owner (manage menu & orders)  
- Delivery Agent (handle deliveries)  
- Admin (monitor platform & analytics)  

---

## 📂 Key Highlights
- Built 10+ REST APIs for order & user management  
- Integrated AI for recommendations & chatbot  
- Real-time updates and scalable backend design
